MOBA SITE — QUICK START

Requirements: Node.js 22+ recommended.

1. Extract this folder.
2. In a terminal, open the moba-site folder and run: npm ci
3. Copy .env.example to .env.local and fill in the Supabase URL and publishable/anon key if you want the site connected to Supabase. Never use a Supabase secret/service_role key in browser config.
4. Run npm run dev to preview locally.
5. Run npm run build to create the production site in dist/.

This archive contains the React/Vite source, public assets, and Supabase migrations. It excludes node_modules, the generated dist build, Git history, and local environment secrets.
